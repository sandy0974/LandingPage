# Sandy Purnama — Personal Landing Page

Landing page portfolio sederhana yang siap di-upload ke GitHub Pages.

## Cara upload ke GitHub

1. Buat repository baru di GitHub, misalnya `portfolio`.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save.
7. GitHub akan memberikan alamat website.
